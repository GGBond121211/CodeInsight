# EXP-001 九格完成记录（2026-09-04）

## 结论层级

这是固定 Master-200、四个冻结仓库、当前真实 `qwen3.7-text-embedding`、BM25 + semantic + 确定性代码重排、最终 Top-5 条件下的确定性对照。它支持当前项目的固定行基线选择，不证明跨数据集、跨 Embedding 或跨检索管线的通用最优参数。

`80 行 + 0% overlap` 曾作为 Step 4 的固定行运行基线：严格 complete evidence coverage `0.7917`，evidence recall `0.9070`，均为九个 profile 最高。学习复核发现案例级上下文行数的统计口径没有充分定义，因此该结果目前只作为探索性观察，切分政策仍未测试完成。

数据集共有 200 个案例，其中 192 个有期望 Evidence。`complete coverage` 要求每一个期望 Evidence 区间都被返回块完整覆盖；`evidence recall` 是期望 Evidence 被返回块覆盖的平均比例。

## 解释

- 40 行块过小，跨函数、跨文件和长证据范围更容易被拆散。
- 120 行块的 evidence line recall 较高，但上下文成本明显增加，且 complete coverage 仍低于 80/0。
- overlap 没有稳定提升质量。80 行下 0% 明显优于 10% 和 20%；120 行下 20% 高于 0%，说明 overlap 的效果依赖 chunk size 和具体案例。
- 正 overlap 带来重复上下文；重复比例随 overlap 大体上升，最高观测约 3.89%。重复块还可能改变 Top-5 候选排序，因此不能只看边界覆盖率。

## 运行失败与有限重试

第一次运行在 7/9 profile 后收到 `429 insufficient_quota`。随后做了最多 3 次、5 秒/15 秒退避的短探针，第一次有效探针成功并返回 1024 维向量、23 input tokens，于是只补跑剩余两个 profile。这样既验证了该次 429 具有暂时性，也避免无条件重复整个实验。

# EXP-001B：固定行切块与结构优先切块对照

- 日期：2026-09-04
- 数据集：冻结 Master-200，4 个冻结仓库，200 个案例，其中 192 个有期望 Evidence
- Embedding：真实 Windows 用户环境中的 `qwen3.7-text-embedding`
- Chat 调用：0
- 检索管线：BM25 + semantic + 确定性代码重排，Top-5

## 对照

| profile | 规则 |
| --- | --- |
| `fixed-80-00` | 固定 80 行，0% overlap；EXP-001 选出的当前固定行基线 |
| `structural-v1` | Python 顶层 class/function/module 区域优先，结构过长时回退固定 80 行；非 Python/语法错误回退固定行 |

## 探索性结果，不是最终判定

当前固定查询集和检索管线下，结构优先切块的探索性指标显示上下文更短、Citation precision 更高，但召回指标更低。由于案例级结果将每个子问题的返回块合并后再求行数，且“Top-5 上下文”不等于完整 Prompt，上述结果暂不足以正式否决结构优先方案。

当前状态为**未测试完成 / 待复测**：fixed-80/0 只是临时运行基线，结构优先方案保留为候选。复测前需要先重新定义实验单位、Top-K 合并规则和 Evidence/Token 成本口径。
